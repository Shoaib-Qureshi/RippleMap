# Changelog

## 0.1.0 (preview)

First public preview.

- See what Claude Code (and any save) changed: Edit Feed, gutter highlights, before/after graph diff, and a
  preview of a proposed edit before it is written.
- File and function graphs for JavaScript, TypeScript, PHP and Python, with WordPress, Express, Next.js,
  Flask and FastAPI flows; "Show flow of…" for one function; Simple mode for big projects.
- "Start here" overview: entry points, core files, files nothing imports.
- What each file does (doc comments plus facts), and optional "Explain with AI" (your own API key).
- Instructions for the AI per block, sent to Claude Code when it edits that file.
- Agent Activity: MCP calls, web fetches/searches and network commands made by Claude Code (and MCP calls
  made by Cursor).
- Export as PNG, SVG or Mermaid; open the graph in a browser tab or a separate window.

## 0.0.1

First working build: edit tracking, Claude Code hooks, file + function graphs, before/after diff,
pending-edit preview, WordPress/Express/Next/Flask flows, time scrubber, insights, PNG/SVG/Mermaid export.
